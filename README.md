🧮 Calculator -- CodeAlpha Internship

A modern, responsive calculator web application built using HTML, CSS,
and JavaScript as part of my CodeAlpha Front-End Development
Internship.

The project focuses on creating a clean and interactive user interface
while implementing calculator operations and additional features using
JavaScript.

⌨️ Keyboard Support

The calculator can also be operated using the keyboard:

0–9 → Enter numbers

+ → Addition

- → Subtraction

* → Multiplication

/ → Division

. → Decimal point

% → Percentage

Enter → Calculate result

Backspace → Delete the last character .


Escape → Clear the display

Dark mode

00

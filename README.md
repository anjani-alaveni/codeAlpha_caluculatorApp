# 🧮 Calculator – CodeAlpha Internship

A modern and responsive calculator built using **HTML, CSS, and JavaScript** as part of my **CodeAlpha Front-End Development Internship**.

The project focuses on creating a clean user interface and implementing basic calculator operations using JavaScript.

## 📌 Features

* Basic arithmetic operations

  * Addition `+`
  * Subtraction `−`
  * Multiplication `×`
  * Division `÷`
* Percentage calculation `%`
* Decimal number support
* `00` button
* Clear (`AC`) button
* Backspace functionality
* Equal (`=`) button
* Error handling for invalid expressions
* Responsive design for different screen sizes
* Interactive button hover and click effects

## 🛠️ Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling, layout, grid system, and responsiveness
* **JavaScript** – Calculator functionality and user interactions

## 🎨 Design

The calculator uses a modern dark-themed interface with:

* Dark background
* Distinct colors for operators
* Separate styling for the clear button
* Highlighted result button
* Rounded buttons
* Hover and active animations
* Responsive layout using CSS Grid

## 🧮 Calculator Layout

The interface consists of two main sections:

### Display Section

Displays the current number or calculation expression.

### Button Section

Contains:

* Numbers
* Arithmetic operators
* Percentage
* Decimal point
* Clear button
* Backspace
* Result button

## 📱 Responsive Design

The calculator is designed to adapt to different screen sizes, including:

* 💻 Desktop
* 📱 Mobile
* 📟 Tablet

CSS Grid, flexible widths, and responsive sizing are used to maintain a usable interface across devices.
